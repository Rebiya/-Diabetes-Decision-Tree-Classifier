# Diabetes Decision Tree Classifier

This repository demonstrates using a Decision Tree to classify whether a patient is diabetes-positive using the Pima Indians Diabetes dataset.


What this repo contains
- A simple, reproducible example using scikit-learn's DecisionTreeClassifier.
- Train script with train/test split and evaluation metrics (accuracy, precision, recall, f1).
- CLI predict script to make single-record predictions.

Notes
- The dataset is not included; follow the instructions in `data/README.md`.
